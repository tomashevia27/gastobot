# Instrucción 03 — Implementar el plan aprobado

Leé AGENTS.md y docs/features/create-expense.md.

Implementá el plan aprobado que incluyo al final de este mensaje. Si falta el plan, primero recuperalo de esta sesión o proponelo para revisión; no adivines qué fue aprobado.

Respetá el alcance: creación manual, persistencia, lista mínima y total del mes actual. Usá TDD para las reglas de dinero y validación, y pruebas de integración reales para PostgreSQL. Agregá el recorrido de navegador de la especificación.

Completá las migraciones, documentación e integración continua correspondientes.
Ejecutá lint, verificación de tipos, pruebas unitarias, de integración y de extremo a extremo, y compilación; reportá cuáles corriste, resultados y bloqueos. No ocultes fallas ni uses la base de desarrollo como base de pruebas.

Al terminar explicá qué cambió, cómo viajan los datos y qué debería revisar en el diff. No agregues funciones vecinas ni hagas commits, envíos remotos o despliegues.
